# No Network While Roaming Abroad — Runbook

## Overview
Use this when a customer has landed in another country with a roaming pack active but the
phone shows no service or no data.

## Steps
1. Confirm a valid roaming pack is active for that specific country and date.
2. Ask the customer to restart the handset to trigger a fresh network search abroad.
3. Turn on "Data Roaming" in settings; it is off by default on many handsets.
4. Manually select a listed partner network under Settings > Network Operators.
5. Set network mode to "Auto" so the device can attach to whichever partner band is
   available locally.

## Escalation
If a partner network still will not register after manual selection with an active pack,
route to ROAMING_PARTNER_DESK with the country, the partner network attempted, and local
time. Partner-side registration issues cannot be fixed on the device.
