# Enable Wi-Fi Calling (VoWiFi) — Runbook

## Overview
Use this runbook to enable Wi-Fi Calling so a customer can make and receive calls over a
Wi-Fi network where mobile signal is weak. This resolves many indoor coverage and
call-drop complaints.

## Steps
1. Confirm the handset supports VoWiFi and the plan/SIM is VoWiFi-provisioned.
2. Enable VoLTE first under Settings > Mobile Network.
3. Turn on "Wi-Fi Calling" in the same menu and set the preference to "Wi-Fi preferred".
4. Connect to a stable Wi-Fi network and confirm the status bar shows the Wi-Fi Calling
   indicator.
5. Place a test call over Wi-Fi with mobile signal covered or in a known dead zone.

## Note
Wi-Fi Calling quality depends on the broadband connection. Emergency calling behaviour over
Wi-Fi varies by region and is governed by regulatory rules.
