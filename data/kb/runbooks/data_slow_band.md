# Slow Data Despite Full Signal — Band and Congestion Checks

## Overview
Use this when the customer has full bars but browsing and streaming are slow. Full signal
with slow throughput usually means cell congestion, a device locked to a weaker band, or a
background app consuming bandwidth.

## Steps
1. Run a speed test twice, a minute apart, and record download and upload in Mbps.
2. Set network mode to "5G/4G Auto" so the device can pick the fastest available band.
3. Toggle Airplane mode to force reselection to a less congested cell.
4. Check for background downloads, OS updates or a hotspot client consuming data.
5. Compare speeds at a different time of day; peak-hour congestion clears off-peak.

## Escalation
If measured speeds stay far below the plan's expected range at multiple times of day in a
non-FUP state, raise it so the radio team can check for a congested serving cell.
